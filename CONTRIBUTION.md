# Contributing to popscript

Thank you for your interest in contributing to popscript!

popscript is developed using a maintainer-reviewed contribution model.
Anyone can propose improvements, fixes, documentation, or other changes,
but all contributions must be reviewed before they become part of the
official project.

## How to contribute

1. Fork the popscript repository.
2. Create a separate branch for your changes.
3. Make your changes.
4. Test your changes.
5. Commit your changes with a clear commit message.
6. Open a Pull Request against the `main` branch.
7. Describe what you changed and why.

Do not submit unrelated changes in the same Pull Request.

## Pull Requests

Every Pull Request is reviewed by the popscript maintainer.

A Pull Request may be:

* accepted and merged;
* returned for changes;
* rejected.

Opening a Pull Request does not guarantee that the changes will be
accepted.

The maintainer has final authority over what is included in the
official popscript project.

## Before submitting a Pull Request

Please make sure that:

* your changes compile successfully;
* existing tests still pass;
* new functionality is tested where practical;
* you have not introduced unnecessary dependencies;
* your changes follow the existing code style;
* your Pull Request has a clear description;
* your changes are related to the purpose of the Pull Request.

## Bug fixes

Bug fixes are welcome.

If you find a bug, you can:

1. Open an Issue describing the bug; or
2. Fix the bug and submit a Pull Request.

When reporting a bug, include:

* what happened;
* what you expected to happen;
* steps to reproduce the problem;
* relevant logs or error messages;
* your operating system and environment when relevant.

## New features

For large features or architectural changes, please open an Issue
before implementing them.

This allows the maintainers to discuss the proposed design before
significant development work begins.

Small improvements can generally be submitted directly as Pull
Requests.

## Contributions and licensing

By submitting code, documentation, or other material to popscript, you
confirm that you have the right to submit that material.

Contributions accepted into the official project are subject to the
popscript Source-Available License.

Submitting a contribution does not transfer ownership of your original
copyright to the project unless a separate written agreement states
otherwise.

The project maintainer receives the rights described in the popscript
license to use accepted contributions as part of popscript.

## Code ownership

The popscript source code and project identity remain under the control
of the project copyright holder.

Contributors do not receive permission to redistribute the popscript
source code or create independent public projects based substantially
on it merely by contributing to the project.

## Communication

Please keep discussions respectful and technical.

For significant changes, use GitHub Issues or Discussions before
starting implementation.

## Maintainer

The popscript maintainer has final authority over:

* the `main` branch;
* accepted Pull Requests;
* project architecture;
* official releases;
* project direction;
* granting additional permissions.

Thank you for helping improve popscript!
